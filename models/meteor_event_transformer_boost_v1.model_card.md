# 流星分類 Transformer EventBoost v1

作成日：2026年10月9日。学習済みモデルは
`meteor_event_transformer_boost_v1.pth`、設定は同名の `.pth.meta.json` です。
画像特徴抽出器と分類器の重みを一つのファイルに保存しています。

## 今回の方式

従来の独自CNNの追加学習から変更し、自己教師あり事前学習済みの
[DINOv2-Small](https://huggingface.co/facebook/dinov2-small) による転移学習を使います。
差分画像と時間を色で表現した画像から画像特徴を抽出し、フレームごとの形状、
移動速度、移動の直線性、明るさの変動、軌跡の空間・時間表現と合わせて、
勾配ブースティング決定木を教師あり学習しました。

- 入力特徴：3,713次元（うち画像Transformer由来は1,536次元）
- 分類器：600本の決定木、最大7葉、学習率0.05、L2正則化3.0
- 画像特徴抽出器：DINOv2-Small、固定重み、22,056,576パラメータ
- 事前学習重みのリビジョン：`ed25f3a31f01632728cabb09d1542f84ab7b0056`
- 判定閾値：`0.8822220810862557`（アプリがモデル設定から自動適用）
- カメラ名、撮影日、ファイル名、旧モデルの予測値は入力に使用しません。

画像特徴抽出器を一から再学習したモデルではありません。
このデータセットで新しく学習したのはイベント分類器です。
推論時は外部通信をせず、保存済みの重みだけで動作します。

## データと評価

`ml_training_data/reviewed` の人が確認したラベル5,391件から、
動画のSHA-256が同じ重複19件を除いた5,372件を使いました。
未確認・スキップ済みの事例は学習対象外です。
同一動画に異なるラベルがある場合は学習を停止します。

| 用途 | 件数 | 流星 | 非流星 |
|---|---:|---:|---:|
| 分類器の学習 | 4,173 | 2,434 | 1,739 |
| モデルと閾値の調整 | 1,019 | 591 | 428 |
| 10月8日・9日の評価 | 180 | 145 | 35 |

撮影日が学習・調整・評価の間で重ならないように分割しました。
8月以前のデータから調整用の撮影日を決め、モデル候補と閾値はその調整用データの
F1で選定しています。評価後に全データへ再学習していないため、配布する重みは
以下の評価を実施した重みそのものです。

| 指標 | 新モデル | 旧Universal v2 | 旧Universal v1 |
|---|---:|---:|---:|
| 正解率 | **95.56%** | 87.78% | 88.33% |
| 適合率 | **95.36%** | 88.20% | 88.75% |
| 再現率 | **99.31%** | 97.93% | 97.93% |
| F1 | **0.9730** | 0.9281 | 0.9311 |
| 誤検出（FP） | **7** | 19 | 18 |
| 見逃し（FN） | **1** | 3 | 3 |

同じ180件に対し、それぞれの保存済みの判定閾値を使った比較です。
旧モデルの学習日もこの2日とは重なりません。
新モデルの調整用1,019件での正解率は98.33%、適合率99.65%、再現率97.46%です。

**評価の限界：**方式を試行する過程で10月分を含む集計結果を確認しているため、
この比較は探索的評価です。完全に未参照の前向き評価ではありません。
10月分を分類器の学習や閾値の算出には使っていませんが、評価は2撮影日・非流星35件に
限られます。将来の撮影日や未経験のカメラで同じ精度を保証するものではありません。

## アプリで使う

アプリを再起動すると今回のモデルが選択されます。
SwiftUI版では「設定 → 検出モデル → 登録済みモデル」から
「Transformer（転移学習・時系列）」「従来モデル：Universal v2」
「従来モデル：Universal v1」を選べます。
旧GUI版でもモデル選択欄から切り替えられます。
`model_epoch_47.pth` など従来の画像CNNも引き続き利用できます。

モデルを移動する場合は `.pth` と `.pth.meta.json` を一緒に配置してください。
このモデルにはイベント動画のフレーム列が必要です。単独の静止画用モデルではありません。

## 再学習・再評価

プロジェクトのルートで実行します。学習には確認済みの元データが必要です。
初回学習時だけ、ローカルにないDINOv2の重みを公式配布元から取得します。

```sh
.venv-mac/bin/python train_event_boost.py
.venv-mac/bin/python evaluate_event_boost.py --model models/meteor_event_transformer_boost_v1.pth
```

学習用・調整用・評価用の日付、データの指紋、候補別の結果、採用設定は
`.pth.meta.json`、旧モデルとの比較は `.comparison.json` に記録しています。
各サンプルの分割と予測はローカルの `.evaluation.json` に保存します。

## 動作確認

- Python全体：324件のテストと15件のサブテストに合格。
- SwiftUIアプリ：ビルド成功。
- 実際のイベント12件：アプリの推論値と学習時に保存した推論値の差は0。
- 旧Universal v1/v2、旧画像CNN：読み込み・推論・新モデルへの復帰を確認。
- このMacでの前処理込み推論時間：中央値約75ミリ秒／件。
