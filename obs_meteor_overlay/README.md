# OBSと旧UIの検出マスク同期

OBSの「直近の流星GIF」ブラウザソースで `index.html` を読み込み、
ツール → スクリプトで `obs_meteor_overlay.lua` を登録します。
OBSを開いている間はプレビュー・配信の両方で更新し、終了すると更新処理を停止します。

## 参照する旧UI設定

通常は `~/Library/Application Support/MeteorDetector/app_settings.json` を参照します。
このファイルがない開発環境では、プロジェクト直下の `app_settings.json` を参照します。
設定に `detection_mask_path` があればそのNPZを使い、なければ設定ファイルと同じ
フォルダの `app_masks.npz` を使います。相対パスは設定フォルダを基準にします。
SwiftUIへ移行・コピーされたマスクではなく、旧UIが使用する保存データを参照してください。

旧UIの検出マスクを確定すると、`apply_mask_var` の変更をきっかけに
`legacy_mask_sync.py` がマスクと適用状態を即時保存します。
「検出マスクを適用する」を解除した場合もOBSに反映します。
プレートソルブ用マスクは用途が異なるため、この同期の対象にはしません。
保存データの一時的な読み込み失敗時は直前の正常なマスクを維持し、ログに記録します。

## 映像への適用

カメラ映像には「旧UIの検出マスク（自動同期）」という画像フィルタを追加します。
Luaの設定でカメラ映像のソース名（初期値「メディア」）を指定できます。
旧UIと同じく0以下のマスク画素を黒にし、正の画素を表示します。
元の解像度でマスクを適用するため、OBSの位置・拡大率・切り取りにも追従します。
カメラの解像度とマスクが異なる場合はOBSフィルタ側で画像を伸縮します。
完全に同じ境界画素が必要な場合は、そのカメラ解像度で旧UIのマスクを作成してください。

右下の全体・拡大GIFは、保存されたイベント情報の元映像から生成します。
マスクは拡大部分の切り出し・縮小・GIF化より前に適用します。
マスクが変われば、イベントが同じでもGIFを作り直します。
元映像がなければ保存済みフルサイズ映像を使い、拡大部分もそこから切り出します。
その場合、保存時に既に黒くなっている領域を復元することはできません。
フルサイズ映像もないイベントは、誤った位置にマスクを適用する代わりに更新エラーを記録します。

設定・マスクは2秒間隔で確認し、カメラフィルタも2秒間隔で同期します。
GIFの更新には映像の変換時間が加わります。GIFと時刻は変換が成功した後に更新します。
保存画像・状態JSON・ログ・PIDは生成物としてGitから除外します。

## 手動起動

Python環境には `requirements.txt` のライブラリとffmpeg/ffprobeが必要です。
`launch_overlay.sh` はプロジェクトの `.venv-mac` とHomebrewのffmpegを優先します。

```bash
./obs_meteor_overlay/launch_overlay.sh --foreground
```

終了はControl+C。OBSのLuaスクリプトが登録済みの場合は自動起動を使ってください。
別の旧UI設定を参照する場合はPythonに `--legacy-settings /path/to/app_settings.json` を指定します。

旧UIを実行中にコードを更新した場合、即時保存を有効にするには旧UIの再起動が一度必要です。
OBS側はLuaスクリプトの再読み込みで反映できます。
