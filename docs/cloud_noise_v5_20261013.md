## 実装

主分類器v5は固定DINOv2-smallエンコーダーと、連続画像・運動特徴から学習した新しい木モデル。画像エンコーダー自体の追加学習はしていない。モデルのしきい値は0.17177035153000328。以前の主分類器が正しく分類した確認済みの開発meteorを維持する条件を学習時のしきい値選択に加えた。

一次分類器は64画素の連続画像の74特徴を使う。以前の補助データに加え、新しく確認された雲・ノイズの負例も学習対象にした。しきい値は0.00840118635499679。確認済み学習meteorと、主分類器が正しく分類した検証meteorに10%のスコア余裕を設けて保持した。時刻・日付・ファイル名・カメラ識別子・保存済みの予測ラベルは分類特徴に使わない。

アルゴリズムとI/Oは次を変更した。

- 過去の検出結果を時間区間で索引化し、重複検査で関係のある時刻だけを調べる。登録順・重複条件を維持する。
- 点の予測をまとめて計算し、判定境界に近い距離は元の計算で再確認する。移動点の対応付けは空間索引で不可能な組だけを除き、元の距離・スコア・同点順序で決定する。
- 密なノイズの成分得点と最大値をまとめて集計する。整数画素の中央値・偏差・分位点は同じ値を返すヒストグラムと配列配置で計算する。大きな中央値計算だけを、最大8スレッドの共通プールに分割する。
- CPUでの分類前処理を並列にし、GPUへの投入は引き続き直列にする。イベントごとにモデルを固定し、途中のモデル更新で重みを混ぜない。木の単体推論ではPythonスカラーを再利用する。
- 詳細検出の完全な読み込み範囲を主検出にも再利用し、独立した読み取り位置を保つ。連続範囲は1つの側方デコーダーで読む。メモリ上限と不完全な読み込みの扱いを維持する。
