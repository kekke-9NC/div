# 流星確率で一括選別（旧UI）

保存設定から「機械学習データ目視レビュー」を開き、右上の「流星確率で一括選別」を押します。

1. **検出時の流星確率**を0〜1で入力し、「以下（≤）」または「以上（≥）」を選択します。境界値を含みます。検出時に保存した確率を使うため、モデルを再実行する必要はありません。
2. 必要に応じて対象日（YYYY-MM-DD）や予測ラベルを絞り込みます。日付が空欄なら全日付が対象です。「表示中の検出日」で現在のサンプルと同じ日を指定できます。
3. 「対象件数を確認」で検索し、件数を確認して「一括 skip」「一括 meteor」「一括 not_meteor」を押します。

たとえば確率0.10以下を一括skipにすると、該当する未確認サンプルは学習に使わずレビュー対象から外れます。0.90以上を一括meteorにすると、そのサンプルを学習用の流星として確定できます。予測ラベルは対象の絞り込みに使い、選別先の分類はボタンで指定します。

対象は未確認データだけです。確定済み・スキップ済み、確率が未保存・不正なデータ、壊れたメタデータ、リンク先のデータは変更しません。条件を変更した場合はもう一度件数を確認してください。確認時点の対象を使用し、検索後に追加されたデータは含めず、移動・メタデータ変更されたデータも処理しません。

検索と保存は別スレッドで行い、動画や画像を読み込まずに検索します。「処理を中断」で現在の1件が終了した時点で停止します。保存エラーでもそれまでの成功分は保持し、エラーになった1件の変更を戻します。処理件数と除外件数を画面に表示します。

「前回の一括処理を戻す」で、最後の一括処理の残っている判定・スキップをまとめて未確認に戻せます。一括処理のIDは履歴に保存するため、レビュー画面を閉じても復元できます。従来の件数指定による復元も使えます。中断・エラーの後も処理済み分を戻せます。

meteor / not_meteorの確定は、従来の個別判定と同様に、検出動画・画像の保存フォルダも確定ラベルに合わせて移動します。復元時には保存フォルダの変更も戻します。skipはサンプルを`skipped`へ移動し、検出動画・画像の分類は変更しません。
