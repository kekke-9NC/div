## 未確認サンプル894件の比較

v5が保存した判定はmeteor 747件、not_meteor 147件です。レビュー用クリップをv6主分類器に入力すると、meteor 172件、not_meteor 722件になりました。

| 保存済みv5判定 → v6判定 | 件数 |
|---|---:|
| meteor → not_meteor | 578 |
| not_meteor → meteor | 3 |
| 合計の変化 | **581 / 894（65.0%）** |

保存済みv5判定との単純比較では、meteor判定が575件減ります。この数字はレビュー用クリップに対するv6再推論を、保存済みv5ラベルと比べた推定です。

同じMP4クリップでv5とv6を両方再推論した比較では **184 / 894（20.6%）** が変わりました（meteor→not_meteor 178件、逆方向 6件）。こちらの方がモデル間比較として公平です。

## 推定の限界

未確認894件すべてで、metadataが指す元RTSP動画はすでにありません。保存クリップはMP4V圧縮した256画素の切り出しで、保存済みv5確率はライブフレームから計算されています。そのため、クリップからv5を再計算すると保存ラベルと **455 / 894件** 食い違い、確率差の中央値は **0.149** でした。したがって、前表の581件を実運用での確定変更件数としては扱えません。現存データで最も比較しやすい数は、同一クリップで再推論した184件です。ライブ時の元フレームを使った厳密なv6再判定は、元動画がないため復元できません。

v6の主分類器と補助ゲートは作成し、アプリのモデル一覧から選べるよう設置しました。現在選択中のモデルはv5のままです。

全894件の推論結果は docs/v6_pending_comparison_20261014.json、保存済みv5判定からv6クリップ推論で変わる581件の一覧は docs/v6_pending_comparison_20261014.changed.csv にあります。
