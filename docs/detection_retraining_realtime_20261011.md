## 処理を軽くした方法と保存物

1. 密な背景ノイズの成分を画像全体でまとめて集計。同じ候補・得点・同点時順序・上位400件を維持する。
2. 重なる読み込み範囲を上限付きキャッシュに保持し、詳細検出で読み込んだ完全な範囲を最終切り出しにも再利用。画素・マスク・フレーム範囲は維持する。
3. 一次分類を既存の詳細検出スレッド内で並列に計算。明確に非流星の候補では重い画像エンコーダーと大量の動画生成を省く。
4. 主分類器のスコアが0.01未満の非流星では、拡大動画・画像・情報・学習クリップを保存し、全体動画と概要動画を省く。流星の保存内容は維持する。

一次分類で除外した候補は原動画と位置・フレーム範囲等のJSON記録を残す。一次分類のスコアは流星確率の確定値ではなく、結果の `classification_stage` で通常分類と区別する。

検出候補生成の条件、fps、解像度、マスクを緩めたり、明るい時間帯を丸ごと停止したりして速度を稼いだものではない。ただし非流星の保存物は上記のとおり減る。以前の「判定・保存を完全に同じにする最適化」とは条件が異なる。

## 再学習手順

```sh

  --extra-reviewed-root ml_training_data/experiments/retrain_20261011/hard_negatives \
  --test-nights 2026-10-08 2026-10-09 --validation-before 2026-10-10 --correction-weight 1
```
