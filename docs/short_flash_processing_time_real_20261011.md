## 結果の解釈

今回の通常環境でも、追加した光点追跡と候補の分類・保存の分だけ改良前より時間が増える。
前回からGPU・CPU並列数・優先度・保存処理を変えているため、前回の測定との差にはこれらすべての影響が含まれる。
20:30は改良前0件、改良後35件の候補を分類・保存。改良後1回の出力は421ファイル、約34MB（一時ファイルを含む）。候補の少ない23:30では改良後も出力なし。
02:25は同じ流星を改良前が2件、改良後が1件に統合して保存した。

明るい夕方・明け方は、GPUを使っても180秒で未完了。大量のノイズ候補に対する分類に加えて、候補ごとの動画・学習データ保存が発生しており、明るい映像への追加対策が必要。
180秒超は実測の下限であり、完了時間は測定していない。分類器の出力件数を流星の正解個数とはみなしていない。

## 旧UIへの適用状況

旧UIの実行先 `~/Library/Application Support/MeteorDetector` に改良版を配置済み。
`config.py` の `SHORT_FLASH_DETECT_ENABLED = True` と、追加モジュールの読み込みを確認した。今回の実測でもこの配置先のコードが実行されている。

起動済みプロセスへの途中での自動反映は行わない。調査時点の旧UIプロセスは0件だった。
作業フォルダの `run_mac.command` はSwiftUI版へ転送するため、旧UIを使う場合は上記の `流星app.app` を起動する。
